# Portfolio

Personal site of Houssam Djerir, published with GitHub Pages at <https://sameeva.github.io/>.
Plain static site: `index.html`, `styles.css`, `app.js`. No build step, no dependencies.

## Editing

- **Copy** lives in `app.js`, in the `T` object, once per language (`en`, `fr`, `ar`).
  Edit all three, and keep the same keys in each.
- **Layout and style** live in `styles.css`; the page structure is `index.html`.
- **Projects** (links, screenshots, status) are in the `PROJECTS` object in `app.js`.

## Generated parts of `index.html`

Some parts of `index.html` are generated by `scripts/sync-static-text.js`: the English text inside
`[data-i18n]` elements (so search engines and visitors without JavaScript see real content), the
`<meta>` description and social tags, the `?v=` hashes on `styles.css` / `app.js` (so browsers never
load an old cached script with a new page) and the Content-Security-Policy hash.

You normally do not need to run it: the GitHub Action in `.github/workflows/sync.yml` runs it after
every push to `main` and commits the result. To run it yourself (needs Node):

```
node scripts/sync-static-text.js          # regenerate
node scripts/sync-static-text.js --check  # only check; exit 1 if out of date
```

It also fails if French or Arabic is missing a key that English has.

## Notes

- A Content-Security-Policy is set with a `<meta>` tag. If you add inline scripts, external scripts,
  fonts, or embeds, update the policy in `scripts/sync-static-text.js`.
- `_config.yml` keeps `scripts/`, `.github/` and this README out of the published site.
